# КВАРД — Balanced Brand Rollout

Статус: компонент и миграция основных пользовательских поверхностей внедрены; wordmark, app icon, theme visual QA и responsive screenshots остаются открытыми. Направление утверждено 2026-11-25.

## Утверждённое направление

**Balanced Premium Technology**:
- светлая нейтральная тема остаётся темой по умолчанию;
- тёмная тема сохраняется как полноценная альтернативная тема;
- интерфейс остаётся сдержанным и функциональным;
- фирменный фиолетовый остаётся цветом действий и выбранного состояния;
- сине-фиолетовый градиент применяется только в фирменном знаке, app icon и редких брендовых акцентах;
- никаких декоративных стеклянных панелей, постоянных свечений, частиц и градиентных заливок рабочих поверхностей.

## Критерии приёмки

- Один и тот же SVG-геометрический знак отображается на всех основных брендовых поверхностях.
- Знак корректно читается при 16, 24, 32 и 48 px.
- Wordmark всегда использует точное кириллическое написание «КВАРД».
- Светлая тема остаётся default; dark theme остаётся рабочей.
- Gradient используется как brand accent, а не как цвет стандартных действий и больших поверхностей.
- Auth, routes, project creation, Builder execution, preview, file operations и Agents не меняют поведения.
- Web typecheck, runtime tests, build, lint и CI проходят.
- Если hosted preview ограничен rate limit, это фиксируется отдельно и не подменяется утверждением о runtime-успехе.
